## ⚙️ Quick Setup Guide (5 Minutes)
Pair STZ Player with a reliable source and solid network for the best experience.

1) Install from official links
- Visit https://stzplayer.com/#/home to find the right version for Android/Android TV, Fire TV, or iOS/tvOS.

2) Add your playlists or portal
- M3U/M3U8: paste your provider URL, name the list, and add EPG if it’s separate
- Xtream Codes: enter server, username, and password; EPG often loads automatically

3) Optimize video settings
- Turn on hardware decoding; toggle only if you see artifacts
- Set buffer to around 5–8 seconds for 4K; increase slightly on unstable Wi‑Fi

4) Organize channels
- Sort by language/country and pin your most‑watched channels
- Enable parental controls to hide sensitive categories

5) Network tips for UHD
- Prefer Ethernet; if Wi‑Fi, aim for Wi‑Fi 6 with strong signal
- Reboot router/modem if persistent buffering occurs; avoid double NAT setups
